# Silas Shop UI – Separated Components

Các ảnh PNG trong `PNG/` hiện được dùng bởi shop, forge và giao diện hội thoại:

- `05_item_slot_empty.png`, `06_item_selection_highlight.png`: ô và viền chọn trong forge.
- `16_item_name_ink_brushstroke.png`: bảng tên hội thoại.
- `23_button_active_blank.png`, `24_button_inactive_blank.png`: lựa chọn hội thoại.
- `26_small_currency_coin.png`: biểu tượng tiền trong shop và forge.
- `29_page_corner_ink_ornament.png`: chỉ báo tiếp tục hội thoại.
- `31_lantern_hanging.png`: đèn trang trí shop.
- `35_detail_panel_blank_optional.png`: nền hội thoại.

Ảnh mockup và sprite sheet gốc được giữ lại làm tài liệu thiết kế.
